# Design

- [direction-a/](direction-a/README.md): the Direction A ("Calm") mockups the owner approved on 15 Nov 2026, one PNG and one HTML page per screen, with the tokens and notes. All names and numbers in them are invented. What gets built from them, and when, is in [docs/spec/14-layouts.md](../spec/14-layouts.md).

The HTML pages are design files only. When opened in a browser they load the Inter font from Google Fonts; the app itself uses no web fonts and sends nothing online.
