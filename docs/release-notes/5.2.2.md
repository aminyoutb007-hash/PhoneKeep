# PhoneKeep 5.2.2

Fixes found while releasing 5.2.1, and Notes shown as on the phone. Everything in [the 5.2.1 notes](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.2.1.md) is still true, plus what's below.

**Verified on a Mac (Apple Silicon) with a real iPhone. The Windows check is deferred:** every automated test runs on Windows on each change, but no check with a real iPhone on a Windows PC was done for this release.

## New in 5.2.2

- **Notes as on the phone.** The phone window's Notes shows your folders (with Pinned and Recently Deleted) and each note as it looks on the iPhone: headings, lists, checklists, tables, pictures, drawings and scanned pages. Audio, videos and files in a note open in the viewer. Save a note, or many, as PDF or as text. A locked note shows a lock: PhoneKeep never asks for your Notes password. Links in a note are shown, never opened.

## Fixed

- **Drag-and-drop no longer stops PhoneKeep opening on older Macs.** The drag-and-drop part PhoneKeep uses needs macOS 14, and on macOS 11, 12 and 13 its failure to load could stop the Mac app opening at all. Now PhoneKeep carries on without drag-and-drop; *File → Open backup…* works as before.
- **No window tabs.** With *Prefer tabs* on in macOS, or in full screen, PhoneKeep's windows could still be merged into tabs whose bar covered the top of the window. The 5.1.2 fix didn't reach the installed Mac app; now it does (checked with the same Tk the installers use).
- **Tamper check on Windows.** When the window and the menu bar helper sealed backups at the same moment, Windows could lose one seal's record, and that backup then showed "can't check". Now each seal waits its turn.

## Known limits

- Everything in [the 5.2.1 notes' Known limits](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.2.1.md#known-limits) is still true.
