# PhoneKeep 5.0

**Verified on a Mac (Apple Silicon) with a real iPhone. The Windows check is deferred:** the Windows installer is built and the automated tests run on Windows in CI, but no on-device Windows check was done for this release; it follows separately.

## What's new

- **Encrypted backups by default**, password kept in the Keychain (Mac) / Credential Manager (Windows). Write the password down too: it is the only way to open the backup.
- **No internet connections** from the app, refused by the app itself; one opt-in *Check for updates…* button.
- **First-run guide**: Connect → Trust → Password → Back up → Done.
- **Menu bar / tray helper**: last backup at a glance, Back up now, notifications, start at login.
- **Automatic backups**, daily or weekly, only when charging if you like.
- **Snapshots over time** with a timeline in the phone window; keep forever, rename, delete; keep the last N or until the disk is 90 % full.
- **Backup location on any drive or NAS**, with a verified move; waits quietly for an unplugged drive.
- **Open any backup** (PhoneKeep's, Finder's or iTunes') with no phone connected; **All files** screen.
- **Plain-language errors** with one fixing button and *Show details*.
- **Cancel** a running backup.
- Engineering: tests in CI on every pull request; test builds labelled `5.0-dev+<feature>`; a backup redaction tool for the test library.

## After updating

- Your existing backups are converted into their first snapshot the first time you back up (a manual copy first is never a bad idea).
- If your iPhone already encrypts its backups, PhoneKeep asks for that password once.
- The menu bar helper appears after the first backup; turn *Start at login* on in Settings if you want it there after a restart.

## Known limits

- **Installers are unsigned** (no Apple Developer ID yet): on a Mac, right-click PhoneKeep → Open → Open the first time, or System Settings → Privacy & Security → Open Anyway. macOS also asks once per executable to allow Keychain access; click *Always Allow*. A signed release (S4, in 5.1) removes both.
- Windows: untested on a device for this release (see above).
- A phone's newest backup exists twice on disk (the live copy the phone updates, plus the snapshot store), so reckon with about twice the phone's used storage for the first backup.
- One iPhone at a time: with two phones connected, PhoneKeep backs up the first one it finds.
- Not in a backup: saved passwords, Health, Screen Time (Apple's rules); locked notes stay locked.
