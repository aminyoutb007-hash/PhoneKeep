# PhoneKeep 5.2.1

**This is the first published 5.2 version.** 5.2.0 was tagged but never published, because GitHub couldn't build its Apple Silicon installer. Everything in [the 5.2 notes](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.2.md) is in this version, plus what's below.

The Apple Silicon Mac installer for this version was built on the developer's Mac because GitHub's Mac build machines were unavailable; the Intel Mac installer was built by GitHub a few hours later.

**Verified on a Mac (Apple Silicon) with a real iPhone. The Windows check is deferred:** every automated test runs on Windows on each change, but no check with a real iPhone on a Windows PC was done for this release.

## Also new in 5.2.1

- **Backups carry on after you close the window.** PhoneKeep tells you with a notification when it needs you (unlock the iPhone, enter its passcode) and when the backup is done. Quitting during a backup asks first.
- **One search across the phone**: *Search everything* in the phone window finds messages, chats, contacts, notes and more, grouped by app, with the matching words highlighted. It searches in memory and keeps no copy of your messages on disk.
- **All your iPhones in one list**: every phone connected now or backed up on this computer, each opening in its own window, even when it isn't connected. The "iPhones nearby" rows are smaller, and the main window scrolls when needed.
- **Dark mode**: Settings → Appearance: *Same as this computer* (the default), *Light* or *Dark*.
- **Chats**:
  - Excel and CSV exports with full detail;
  - show just one person's messages in a group chat;
  - a viewer for photos, videos and files sent in chats.
- **Contacts** with groups, photos and links. **Music** export keeps the tags and artwork.
- **Videos**: saving with *Most compatible* converts iPhone HEVC videos to H.264, so they play everywhere.
- **Security**:
  - an **Activity** record of what PhoneKeep did, kept on this computer;
  - a **Tamper check** that warns if a backup's files were changed after it was made.
- **Faster with very large phones**: the photo grid opens quickly and scrolls smoothly with tens of thousands of photos.
- Fixes:
  - the Storage screen could freeze when the iPhone's app list failed;
  - closing a phone window while it was still reading could crash PhoneKeep;
  - a phone's battery could go blank in the main window.

## After updating

- Nothing to do: your backups, snapshots, settings and backup password carry over.

## Known limits

- PDF previews on Windows haven't been tried with a real iPhone yet.
- On Windows, *Most compatible* saves iPhone HEVC videos as they are; converting them to H.264 works on a Mac only for now.
- On Windows, a backup that carries on after the window closes can't show a notification yet; the window comes back from the taskbar instead.
- **Installers are unsigned** (signing is planned for 5.3): on a Mac, right-click PhoneKeep → Open → Open the first time, or System Settings → Privacy & Security → Open Anyway. Windows: if SmartScreen warns, click *More info → Run anyway*.
- Not yet: restoring a backup to an iPhone, removing cleaned-up photos from the iPhone, and the spyware check. They are planned for 5.3.
- Everything else from [the 5.1 notes](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.1.md#known-limits) is still true.
