# PhoneKeep 5.2.4

A fix for closing the main window while a backup carries on. Everything in [the 5.2.3 notes](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.2.3.md) is still true, plus what's below.

**Verified on a Mac (Apple Silicon). The Windows check is deferred:** every automated test runs on Windows on each change, but no check by hand on a Windows PC was done for this release.

## Fixed

- **Settings and Open backup while a backup carries on.** If you closed the main window during a backup (so it could finish on its own) and then chose *File → Settings…* or *File → Open backup…* from a phone window, nothing opened. Now the window opens on its own. While Settings is open, PhoneKeep doesn't quit by itself when the backup finishes.

## Known limits

- Everything in [the 5.2.3 notes' Known limits](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.2.3.md#known-limits) is still true.
- With the main window closed during a backup, a few messages still belong to it: the About box, "PhoneKeep is already working", and the note when a folder chosen in *Open backup → Other folder…* isn't a backup. How they show while it's closed hasn't been checked yet.
