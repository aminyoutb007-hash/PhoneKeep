# PhoneKeep 5.2

**Verified on a Mac (Apple Silicon) with a real iPhone. The Windows check is deferred:** the Windows installer is built and every automated test runs on Windows on each change, but no check with a real iPhone on a Windows PC was done for this release.

## What's new

- **A calmer layout for the main screens**, from the new design:
  - **Phone window**: Save everything at the top, the phone and a Snapshot card on the left (which snapshot you're looking at, how many there are, and that snapshot's date, size and iOS version), the This iPhone, Battery and Storage cards, then everything on the phone as tiles with counts.
  - **Backing up**: one card with the percentage, the time left, what's being copied, the steps, and Cancel. When the iPhone needs you (unlock it, enter its passcode), an amber *Look at your iPhone* notice says so.
  - **Settings**: a list on the left (Backups, Automatic backups, Security, Saving, Activity, About) that takes you to each section. *Activity* shows the newest lines of the activity record PhoneKeep keeps on this computer.
  - **First-run guide**: the four steps on the left, the current one on the right. Choosing a backup password now asks you to type it twice.
- **Use this iPhone over Wi-Fi**, in the first-run guide, after you tap Trust. The switch is off. Turning it on asks first, naming the phone, and only then changes one setting on the iPhone so this computer can reach it over Wi-Fi. Only phones that were connected by cable once can appear over Wi-Fi; PhoneKeep never searches the network for others.
- **Storage tips**: under *Largest apps*, each app says how to free its space: the app's own way to clear downloads or its cache for common big apps (YouTube, WeChat, Spotify and others), and how to offload it in the iPhone's Settings. PhoneKeep never deletes or offloads anything itself.
- **PDF previews on Windows** now show inside PhoneKeep's own preview, like photos and text, instead of opening another app.
- Smaller things: Storage's category tips stay inside their card; the list of apps keeps its place while sizes arrive.

## After updating

- Nothing to do: your backups, snapshots, settings and backup password carry over.

## Known limits

- **Keep PhoneKeep open until a backup is done:** closing the main window quits PhoneKeep. (Automatic backups and *Back up now* in the menu bar or system tray helper already run with the window closed and notify you.) Carrying on with the window closed, with a notification at the end, is planned for 5.3.
- PDF previews on Windows haven't been tried with a real iPhone yet.
- **Installers are unsigned** (signing is planned for 5.3): on a Mac, right-click PhoneKeep → Open → Open the first time, or System Settings → Privacy & Security → Open Anyway. macOS asks once per executable to allow Keychain access; click *Always Allow*. Windows: if SmartScreen warns, click *More info → Run anyway*.
- Not yet: restoring a backup to an iPhone, removing cleaned-up photos from the iPhone, and the spyware check. They are planned for 5.3; restoring and removing photos are tried on a spare iPhone first.
- Everything else from [the 5.1 notes](https://github.com/aminyoutb007-hash/PhoneKeep/blob/main/docs/release-notes/5.1.md#known-limits) is still true.
