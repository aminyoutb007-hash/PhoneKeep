# Tests

Run everything from the repository root:

```
pip install -r requirements.txt
python tests/run_all.py
```

All data is fake and generated by the scripts into `tests/work/` (ignored by git). No real backup or personal data belongs in this repository.

| Script | What it does |
| --- | --- |
| `test_full_backup.py` | Builds a simulated iPhone backup with every supported kind of data (contacts, Messages, WhatsApp, calls, notes, calendar, voicemail, voice memos, Safari, photos, apps) and runs the full export twice (the second run checks incremental export) |
| `make_biz.py` | Copies that backup and adds a WhatsApp Business database with several chats and a group |
| `make_rich.py` | Adds photos across several months, a Live Photo pair, a video, iOS thumbnails and WhatsApp picture messages |
| `test_security.py` | Booby-trapped messages (script injection in the archive pages), files that try to escape the archive folder, and spreadsheet formulas in Excel/CSV. Fails if any gets through |
| `test_phone_window.py` | Opens the real phone window on the fake backup with a **simulated iPhone** (wallpaper, music, books, apps and app files served from memory). Checks the home-screen counts, that every app screen opens (or explains why it's empty), that a save produces a file, and that closing disconnects. Needs a display: Mac and Windows have one; on Linux it runs under `xvfb-run` automatically if installed |

These run on every push and pull request in GitHub Actions (`.github/workflows/tests.yml`) on a Mac and a Windows machine.

Every feature adds tests for the points in its "Done when" that can be automated (see `docs/spec/12-engineering.md`).
