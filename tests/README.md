# Tests

Run everything from the repository root:

```
pip install -r requirements.txt
python tests/run_all.py
```

All data is fake and generated by the scripts into `tests/work/` (ignored by git). No real backup or personal data belongs in this repository.

Window tests keep their windows out of sight with `tkcompat.hide()`, not `withdraw()`: under Tk 8.6 on a Mac (the installers' Tk, and GitHub's Mac machines) a withdrawn phone or Settings window, or one tied to a withdrawn window, makes `update()` spin for ever. A test skips a check only when it measures why it can't be made on that machine (a screen too small for what it checks, a window that isn't viewable there), and prints the reason.

These run on every push and pull request in GitHub Actions (`.github/workflows/tests.yml`) on Linux and Windows; on a Mac by hand (Actions tab) and on release tags.

Every feature adds tests for the points in its "Done when" that can be automated (see `docs/spec/12-engineering.md`).
